# 07 Agent 工具系统

状态：候选

## 职责

定义模型可见工具的名称、描述、参数 schema、执行入口和标准结果。候选工具包括读取、列目录、搜索、写入、补丁和命令执行。

## 边界

- 工具声明与实际执行绑定，但执行前必须经过 08 号权限系统。
- 文件与进程能力来自 01、02 号子系统。
- 不负责对话循环；09 号系统负责调度。

## 设计要求

- 参数验证必须在权限询问之前完成。
- 工具结果需要区分成功、业务失败、拒绝、超时和截断。
- 每个工具保持单一职责，避免一个通用 shell 工具吞掉全部安全边界。

## 待讨论

v0.1 的最小工具集，以及是否首版即允许写文件和任意命令执行。
