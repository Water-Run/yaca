# 02 进程执行与随包资源

状态：候选

## 职责

定位随包工具，安全构造参数并执行 curl、BusyBox、diff、patch、file、iconv、jq、sqlite3 等外部程序；统一超时、输出上限、stdout/stderr、退出码和取消。

## 边界

- 只执行已经结构化的程序与参数，不拼接未经审查的 shell 字符串。
- 权限判定属于 08 号子系统；本系统只执行已获准动作。
- 网络策略属于 03 号子系统，即使底层最终调用 curl。

## 旧系统重点

- Windows 命令行转义和 CreateProcess 语义。
- 旧 Linux/macOS 信号、超时和子进程树清理。
- 输出代码页、二进制输出及 CRLF/LF。
- 随包工具版本、完整性和替换边界。

## 待讨论
