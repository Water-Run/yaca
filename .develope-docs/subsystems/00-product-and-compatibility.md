# 00 产品契约与兼容性基线

状态：讨论中

## 职责

定义 yaca v0.1 是什么、在哪些环境必须工作、什么结果才允许发布，以及哪些能力明确不在首版范围。后续所有子系统必须服从这里的约束。

## 已确认

- yaca 是单 Agent、终端优先的 Coding Agent。
- 主体使用官方 Lua 5.5 语言级别与 ABI。
- Windows XP SP3 x86 是 v0.1 硬性发布目标。
- CentOS 7 x86_64 是 v0.1 硬性发布目标。
- v0.1 不承诺旧 macOS；不建立旧 macOS 专用实现与发布测试矩阵。
- Lua 程序由 `../luainstaller` 打包；发布物不得依赖系统已安装 Lua。
- 设计先于编码，实施时按子系统逐个推进。

## 当前边界

- “支持”必须包含目标环境上的打包产物启动、模型请求、至少一个工具调用、上下文保存与恢复。
- 不能只凭现代系统测试推断旧系统兼容。
- Web 不进入首版关键路径。

## 当前讨论点

现代 Windows 与现代 Linux 的支持等级尚未确定。需要区分“硬性发布门槛”“基础冒烟验证”和“没有正式承诺”，避免把旧平台通过错误地等同于所有现代环境都已通过。

## 验收设计方向

每个硬性目标都需要独立构建记录、干净环境运行记录和功能闭环记录。详细矩阵在本子系统确认后形成。
