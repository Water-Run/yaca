# 13 CLI

状态：候选

## 职责

定义稳定命令行语法，解析参数并调用配置、上下文、诊断和会话服务；负责帮助、版本和可脚本化输出。

## 边界

- CLI 不包含业务逻辑。
- 交互式界面属于 14 号 TUI。
- Unix `--long/-s` 与 Windows `/x` 语法需要一个无冲突规范。

## 设计要求

- 修复当前 `-dc`、`-rc` 短参数冲突。
- 明确退出码和 stdout/stderr 分工。
- 路径和上下文名称可以安全包含空格与非 ASCII 字符。
- 旧 shell 环境不要求现代终端特性。

## 待讨论

Windows 斜杠参数是否继续作为正式契约，还是只保留兼容别名。
