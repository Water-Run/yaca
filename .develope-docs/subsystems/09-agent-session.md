# 09 Agent 会话循环

状态：候选

## 职责

维护一次会话的消息状态，调用模型，解析工具请求，经过权限系统执行工具，将结果送回模型，并处理取消、重试和结束。

## 边界

- 不直接操作终端。
- 不直接读写上下文文件；通过 10 号系统持久化。
- 不理解 curl 或具体模型协议。
- 不在内部隐藏权限确认。

## 设计要求

- 每轮状态变化清晰且可恢复。
- 工具循环必须有次数、时间和上下文预算上限。
- 用户取消与程序异常不能留下半写上下文。
- 一个会话只绑定一个活动模型和权限快照，切换行为需显式记录。

## 待讨论

首版是否允许单轮多个工具调用，以及用户能否在模型生成期间取消。
