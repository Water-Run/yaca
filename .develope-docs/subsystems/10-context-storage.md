# 10 上下文存储

状态：候选

## 职责

持久化会话元数据、消息、工具调用、模型、权限和关联工作目录；提供创建、加载、保存、归档、删除和恢复。

## 边界

- 文件格式底层能力来自 04 号系统。
- 名称与跨目录查找由 11 号系统处理。
- 压缩策略由 12 号系统处理。

## 设计要求

- 原子写入、崩溃恢复和损坏检测。
- 上下文中的 API key、环境变量和敏感工具输出需要明确处理。
- 工作目录移动、删除或无权限时应可打开日志但不能误跳转。
- 格式必须包含版本号和迁移策略。

## 待讨论

XML 是用户可长期依赖的公开日志格式，还是内部、可迁移的持久化格式。
