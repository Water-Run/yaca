# 01 平台兼容抽象

状态：候选

## 职责

向上层提供稳定的操作系统能力接口：平台识别、路径、文件系统、环境变量、工作目录、临时目录、时间、文本编码和终端能力探测。

## 边界

- 不负责启动外部进程；由 02 号子系统承担。
- 不负责 HTTP；由 03 号子系统承担。
- 不绘制 TUI；只提供终端能力事实。
- 上层不应散落 `_WIN32`、路径分隔符或编码猜测。

## 旧系统重点

- Windows XP 路径、代码页、长路径限制和非 ANSI 终端。
- CentOS 7 的 locale、`/proc`、文件权限和旧 glibc 基线。
- 旧 macOS 的最低版本与 CPU 架构等待 00 号确认。
