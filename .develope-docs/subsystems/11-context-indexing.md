# 11 上下文索引与命名

状态：候选

## 职责

将上下文与目录关联，生成稳定标识，支持当前目录与全局列表、名称解析、重命名、自动命名和跳转。

## 边界

- 不保存消息主体；由 10 号系统承担。
- 自动命名可以调用模型，但索引本身必须在无网络时可用。
- CLI/TUI 只展示解析结果，不重复查找逻辑。

## 设计要求

- 名称冲突、哈希优先级和大小写规则必须明确。
- Windows 驱动器号、UNC、路径大小写与 POSIX 路径需要稳定归一化。
- 不依赖目录遍历顺序。

## 待讨论

目录哈希应表示原始路径、规范路径还是可迁移的目录身份；项目移动后的行为也需确定。
