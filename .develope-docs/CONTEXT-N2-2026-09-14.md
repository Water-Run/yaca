## 已接通

`--context-repl recent|full` 中可直接使用：

```text
rename <selector> <new-name>
set-auto-rename-disabled <selector> <true|false>
delete <selector> [--yes]
```

- rename 使用唯一 Resolver 选择与精确 credential 获取短期 writer，在同一镜像目录
  进行 no-replace 生命周期事务，改变逻辑路径/hash，并设置 AutoRenameDisabled=true。
- 命名开关写入专用 metadata 和审计事件；解除禁用以实际完成的 main turn 数与已保存
  waterline 中的较大值建立新 baseline，不立即追补自动命名。
- 生命周期视图哈希排除最后的 publication event，消除自引用；由真实事实前缀计算，
  保留已有压缩投影、摘要及后续事实，下一进程可直接重建，不能只填写任意 manifest 字符串。
- 删除在显示精确 hash/逻辑路径后要求 `DELETE <hash>`，或者使用显式 `--yes`；确认后
  再次复核同一 selection。删除官方 XML 与该事务已知的临时/previous/lock 文件，逐项
  报告结果。损坏 XML 可经专用 Resolver 与不解析正文的删除 writer 处理；HashCollision、
  busy、替换对象拒绝，不用同名替身。
- 每次事务释放 writer；known failure 保留原始错误并可继续，异常、unknown、cleanup
  未完成或 partial delete 停止管理器。有效配置的 registered secrets 不得作为新名称。
- Windows 拒绝设备名、ADS 冒号、通配字符等非普通文件名。代码保持 XP 可用 API 基线，
  本次没有新增 Win32 API。
